# Client 四栏 IM 布局

> 路由前缀 `/client/*`
> 设计范式：仿 Slack/Discord 四栏即时通讯布局

---

## 1. 整体布局结构

```
┌──────┬──────────────────┬──────────────────────────────────┬─────────────────────┐
│ Nav  │  Session List    │  Chat Window                     │  Context Panel      │
│ Bar  │  / Project List  │  (Main Content)                  │  (Optional)         │
│ w-16 │  w-72            │  flex-1                          │  w-80 (可折叠)       │
│      │                  │                                  │                     │
│      │                  │                                  │                     │
│      │                  │                                  │                     │
│      │                  │                                  │                     │
│      │                  │                                  │                     │
│      │                  │                                  │                     │
└──────┴──────────────────┴──────────────────────────────────┴─────────────────────┘
```

### 布局参数

| 属性 | 值 |
|------|------|
| 导航栏宽度 | `w-16` (64px) |
| 会话列表宽度 | `w-72` (288px) |
| 聊天窗口 | `flex-1` (自适应) |
| 上下文面板宽度 | `w-80` (320px)，可折叠 |
| 面板分隔线 | `border-r border-border` 1px |
| 整体高度 | `h-screen`，内部独立滚动 |

## 2. Column 1: 导航栏 (Navbar)

```
┌──────┐
│      │
│  👤  │  ← 用户头像 (40px，点击→个人设置)
│ ──── │
│  💬  │  ← 聊天视图 (高亮当前)
│  📁  │  ← 项目视图
│ ──── │
│  ⚙️  │  ← 设置
│      │
│      │
│      │
│      │
│      │
│  🚪  │  ← 退出登录 (底部)
└──────┘
```

### 导航项样式

| 状态 | 样式 |
|------|------|
| 默认 | `text-muted-foreground` |
| Hover | `bg-accent text-accent-foreground` |
| 选中 | `bg-accent text-accent-foreground` + 左侧 3px 蓝色指示条 |
| 图标 | `h-5 w-5` |
| 容器 | `h-10 w-10 rounded-lg mx-auto flex items-center justify-center` |

### 未读提示

导航栏聊天图标右上角显示未读消息数 Badge（同通知铃铛样式）。

### 路由映射

| 图标 | 视图 | Column 2 内容 |
|------|------|---------------|
| 💬 `MessageSquare` | 聊天 | 会话列表 |
| 📁 `FolderKanban` | 项目 | 项目列表 |
| ⚙️ `Settings` | 设置 | 设置面板 |
| 👤 头像 | — | Popover: 个人资料快捷方式 |
| 🚪 `LogOut` | — | 确认退出 AlertDialog |

## 6. 响应式策略

### 桌面端 (≥1280px xl)

四栏全部展开：

```
┌──────┬───────┬──────────────────┬──────────┐
│ Nav  │ List  │ Chat             │ Context  │
│ 64px │ 288px │ flex-1           │ 320px    │
└──────┴───────┴──────────────────┴──────────┘
```

### 标准桌面 (1024-1279px lg)

三栏，上下文面板默认隐藏：

```
┌──────┬───────┬──────────────────────────────┐
│ Nav  │ List  │ Chat                         │
│ 64px │ 288px │ flex-1                       │
└──────┴───────┴──────────────────────────────┘
```

点击 [📎] 时，上下文面板以 Sheet (右侧滑出) 形式展示。

### 平板 (768-1023px md)

导航栏折叠为底部 Tab Bar：

```
┌────────────────────────────┬─────────────────┐
│ List (w-64)                │ Chat            │
│                            │                 │
│                            │                 │
│                            │                 │
├────────────────────────────┴─────────────────┤
│   💬        📁        ⚙️       👤            │
└───────────────────────────────────────────────┘
```

- 底部 Tab Bar：`h-14`，4 个图标等分
- List 宽度缩减为 256px
- 上下文面板：全屏 Sheet

### 手机 (<768px)

单栏视图，导航为底部 Tab Bar：

```
┌──────────────────────────────┐
│ List (全屏)                  │
│                              │
│                              │
├──────────────────────────────┤
│ 💬     📁     ⚙️     👤     │
└──────────────────────────────┘
```

- 会话列表 / 项目列表全屏
- 点击进入聊天后全屏聊天窗口（左上角返回按钮）
- 上下文面板：全屏 Sheet

## 7. 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + K` | 打开全局搜索 (Command Palette) |
| `Ctrl/Cmd + N` | 新建会话 |
| `Ctrl/Cmd + [` | 返回上一个会话 |
| `Ctrl/Cmd + ]` | 前进到下一个会话 |
| `Alt + ↑/↓` | 切换会话列表 |
| `Escape` | 关闭上下文面板 / 取消搜索 |
