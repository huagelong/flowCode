## 2. 项目卡片

### 样式

| 属性 | 值 |
|------|------|
| 内边距 | `p-4` |
| 圆角 | `rounded-lg` |
| 边框 | `border` |
| 选中态 | `bg-accent border-primary` |
| Hover | `bg-accent/50 cursor-pointer` |
| 间距 | `mb-3` |
| 过渡 | `transition-colors duration-150` |

### 内容元素

| 元素 | 样式 | 说明 |
|------|------|------|
| 图标 + 项目名 | `text-sm font-medium` + `FolderKanban` 图标 | `h-4 w-4` |
| 描述 | `text-xs text-muted-foreground line-clamp-1` | 单行截断 |
| 进度条 | `Progress h-1.5` + 百分比 | 进度条颜色随百分比变化 |
| 统计 | `text-xs text-muted-foreground` | 进行中/已完成数 |
| Agent/成员 | `text-xs text-muted-foreground` | 图标 + 数量 |
| 更新时间 | `text-[10px] text-muted-foreground` | 相对时间 |

### 进度条颜色

| 完成率 | 颜色 |
|--------|------|
| 0-30% | `bg-blue-500` |
| 30-70% | `bg-amber-500` |
| 70-100% | `bg-green-500` |
| 100% | `bg-green-600` |

## 3. 交互行为

| 操作 | 行为 |
|------|------|
| 点击项目 | 进入项目视图（Column 3 显示项目详情） |
| 搜索 | 按项目名/描述实时过滤，debounce 300ms |
| 双击 | 打开项目关联的群组聊天 |

### 排序

列表顶部显示排序切换：

```
│ [🔍 搜索项目...]     [最近更新 ▾]  │
```

| 排序选项 | 字段 |
|----------|------|
| 最近更新 | `last_activity_at` 降序（默认） |
| 项目名称 | `name` 升序 |
| 创建时间 | `created_at` 降序 |
| 完成进度 | `completion_rate` 降序 |

- 使用 Select 下拉，`w-32`
- 排序在前端完成（项目数量通常不多）

## 6. 移动端适配

在手机端（<768px），项目列表全屏显示，卡片垂直堆叠：

```
┌──────────────────────────┐
│ [← 返回]  项目           │
│ [🔍 搜索...]             │
│ ──────────────────────── │
│ ┌──────────────────────┐ │
│ │ 📁 anserFlow         │ │
│ │ AI Agent 协作平台     │ │
│ │ ██░░ 68%             │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 📁 mobile-app        │ │
│ │ 移动端应用            │ │
│ │ █░░░ 30%             │ │
│ └──────────────────────┘ │
└──────────────────────────┘
```

- 项目详情：点击卡片后全屏覆盖列表（`translateX(100%)` 滑入）
- 返回按钮回到列表
- 卡片间距：`p-3`（比桌面端更紧凑）
