## 2. 会话项详细设计

### 2.1 DM 会话 (Human + Agent)

```
┌──────────────────────────────────┐
│ ┌──────┐                         │
│ │  🤖  │  CEO                    │
│ │ 40px │  关于架构方案的讨论      │
│ │      │                    14:30│
│ └──────┘                         │
└──────────────────────────────────┘
```

- 头像右下角 Bot 图标角标 (16px)
- 名称：`text-sm font-medium`
- 预览：`text-xs text-muted-foreground truncate max-w-[160px]`
- 时间：`text-[10px] text-muted-foreground`

### 2.2 DM 会话 (Human + Human)

```
┌──────────────────────────────────┐
│ ┌──────┐                         │
│ │  👤  │  张三               (2) │
│ │ 40px │  明天开会讨论            │
│ │      │                    11:20│
│ └──────┘                         │
└──────────────────────────────────┘
```

- 无 Bot 角标
- 未读数 Badge：右侧

### 2.3 群组会话

```
┌──────────────────────────────────┐
│ ┌──────┐                         │
│ │ 💬   │  项目讨论组         (3) │
│ │ 40px │  🤖CTO: 建议拆分为...   │
│ │      │                    10:15│
│ └──────┘                         │
└──────────────────────────────────┘
```

- 群组头像：显示成员头像 2×2 网格（最多 4 个）或 `MessageSquare` 图标
- 预览：发送者名 + 消息内容截断

### 2.4 待确认会话标记

当群组中有 Agent 生成的 backlog Issue 等待人工确认时，会话列表项显示特殊标记：

```
┌──────────────────────────────────┐
│ ┌──────┐                         │
│ │ 💬   │  项目讨论组   📋 待确认 │
│ │ 40px │  生成了 2 个方案...     │
│ │      │                    10:15│
│ └──────┘                         │
└──────────────────────────────────┘
```

| 属性 | 样式 |
|------|------|
| 标记图标 | `ClipboardList h-3.5 w-3.5 text-amber-600` |
| 标记文字 | "待确认" `text-xs font-medium text-amber-600` |
| 位置 | 会话名称右侧，未读数左侧 |
| 出现条件 | 该群组存在 `status=backlog` 且无 `backlog_ack` 响应的 Issue |
| 消失条件 | 所有 backlog Issue 被确认或拒绝 |

**视觉优先级**: "待确认"标记优先于普通未读数显示，提醒用户需要操作。

## 3. 分组规则

- **"最近"**: 最近 7 天有消息的 DM 会话
- **"群组"**: 所有群组会话
- 各分组标题：`text-xs font-semibold text-muted-foreground uppercase tracking-wider px-3 py-2`
- 会话按 `last_message_time` 降序排列

---

## 5. 交互行为

| 操作 | 行为 |
|------|------|
| 点击会话 | 加载聊天消息，Column 3 显示聊天窗口 |
| 搜索 | 过滤会话列表 |
| 右键会话 | Context Menu: 标为已读 / 置顶 / 静音 / 退出群组 |
| 拖拽排序 | 不支持（固定排序规则） |
| 未读 Badge | WebSocket 实时更新未读数 |

---

## 6. 实时更新

- WebSocket 订阅 `user:{user_id}` 频道
- 收到新消息：
  1. 如果当前会话 = 发送消息的会话 → 自动滚动到底部 + 调用 `PUT read-state`
  2. 如果不是 → 列表项预览文字更新 + 未读数 +1
- 收到 `new_session` → 会话重排序
