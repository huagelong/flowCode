## 3. 详细规范

所有模块（外观、通知、账户）的详细设计规范与 [admin/11-user-profile.md](../admin/11-user-profile.md) 完全一致。

### 主题切换卡片

```
┌────────┐ ┌────────┐ ┌────────┐
│  ☀️   │ │  🌙   │ │  💻   │
│ 浅色   │ │ 深色   │ │ 系统   │
│ (选中) │ │        │ │        │
└────────┘ └────────┘ └────────┘
```

- 三个等宽卡片 `flex-1`
- 高度 `h-20`
- 选中态：`border-primary ring-2 ring-primary/20`
- 切换即时生效
- 保存到 `user_settings`

### 通知开关

每行 `flex items-center justify-between py-3 border-b`：
- 左侧：通知描述 `text-sm`
- 右侧：Switch

### 密码修改

- 仅 email 注册用户可见
- 表单验证规则同 Admin
- 修改成功 Toast + 清空表单

---

## 4. 保存反馈

各设置项采用即时保存模式：

| 操作 | 反馈 |
|------|------|
| 主题切换 | 即时生效，无 Toast |
| 语言切换 | Toast "语言已更新" + 页面刷新 |
| 时区切换 | Toast "时区已更新" |
| 通知开关 | Switch 动画中 → API 调用 → 失败时回滚 + Toast "保存失败" |
| 密码修改 | 按钮 Spinner → Toast "密码已修改" / 字段错误 |
| 头像上传 | Spinner 覆盖 → Toast "头像已更新" / "上传失败" |

## 5. 移动端适配

### 入口点

移动端（<768px）在底部 Tab 栏显示 ⚙️ 图标，点击进入全屏设置页面：

```
┌──────────────────────────┐
│ [← 返回]  个人设置       │
│ ──────────────────────── │
│ 外观                     │
│ ...                      │
│ 通知                     │
│ ...                      │
│ 账户                     │
│ ...                      │
│ [退出登录]               │
└──────────────────────────┘
```

- 底部 Tab 栏图标：`Settings` (lucide) `h-5 w-5`
- Tab 栏顺序：💬 消息 | 📁 项目 | ⚙️ 设置
- 设置页面全屏覆盖，返回按钮回到上一个视图
