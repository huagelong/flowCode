## 2. 与 Admin 设置的区别

| 方面 | Admin 设置 | Client 设置 |
|------|-----------|-------------|
| 布局 | 独立页面 (`/admin/profile`) | 合并 Column 2+3 |
| 内容 | 完全相同 | 完全相同 |
| API | 相同 | 相同 |
| 导航 | 侧边栏 → 用户资料 | 导航栏 ⚙️ 图标 |

---

## 3. 详细规范

所有模块（外观、通知、账户）的详细设计规范与 [admin/11-user-profile.md](../admin/11-user-profile.md) 完全一致。

### 主题切换卡片

```
┌────────┐ ┌────────┐ ┌────────┐
│  ☀️   │ │  🌙   │ │  💻   │
│ 浅色   │ │ 深色   │ │ 系统   │
│ (选中) │ │        │ │        │
└────────┘ └────────┘ └────────┘
```

- 三个等宽卡片 `flex-1`
- 高度 `h-20`
- 选中态：`border-primary ring-2 ring-primary/20`
- 切换即时生效
- 保存到 `user_settings`

### 通知开关

每行 `flex items-center justify-between py-3 border-b`：
- 左侧：通知描述 `text-sm`
- 右侧：Switch

### 密码修改

- 仅 email 注册用户可见
- 表单验证规则同 Admin
- 修改成功 Toast + 清空表单
