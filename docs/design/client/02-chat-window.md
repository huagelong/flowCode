> 位于 Column 3，核心交互区域
> API：`/api/groups/:group_id/messages`, WebSocket

### 2.2 消息气泡样式

#### 用户消息

```

| 最大宽度 | `max-w-[80%]` |

| Bot 角标 | 右下角 `bg-primary text-primary-foreground rounded-full` |

| 分隔线 | 左右各 `border-t border-border flex-1` |

```

```

- 左右各一条 `flex-1 border-t border-border`

### 2.4 滚动行为

| 行为 | 说明 |
|------|------|
| 初始加载 | 滚动到最底部 |
| 新消息（已在底部） | 自动滚动到底部 |
| 新消息（已向上滚动） | 显示 "↓ 新消息" 按钮，点击滚动到底部 |
| 加载更多 | 滚动到顶部触发，保持当前位置（不跳动） |
| "新消息" 按钮 | `fixed` 底部居中，`bg-card shadow-lg rounded-full px-3 py-1.5` |

### 2.5 消息分组

- 同一发送者连续消息合并头像（仅第一条显示头像）
- 5 分钟内同一发送者不重复显示用户名
- 超过 5 分钟显示新的时间戳

## 3. 输入区域

### 3.1 基础输入 (无 Agent 的群组 / 人对人 DM)

```
┌──────────────────────────────────────────────────────────────┐
│ [Aa] 输入消息...                              [😊] [发送 ↑] │
└──────────────────────────────────────────────────────────────┘
```

| 元素 | 说明 |
|------|------|
| 输入框 | Auto-resize Textarea，最小 1 行，最大 6 行 |
| [Aa] | 切换纯文本/Markdown 模式（未来） |
| [发送 ↑] | 主色按钮，`Enter` 发送，`Shift+Enter` 换行 |
| 占位符 | "输入消息..." |

### 3.2 含 Agent 的输入 (Human + Agent DM / 含 Agent 群组)

```
┌──────────────────────────────────────────────────────────────┐
│ [/backlog] [/todo] [/new]                                    │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 输入消息... 使用 @提及 Agent                   [😊] [↑] │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 🤖 CTO · 🤖 前端 · 🤖 后端                                  │
└──────────────────────────────────────────────────────────────┘
```

**命令按钮行**:
- `/backlog`: 生成方案 → Badge "生成待办"
- `/todo`: 直接创建 → Badge "创建任务"
- `/new`: 新会话 → Badge "新会话"
- 仅在群组包含 Agent 成员时显示
- 样式：`bg-muted hover:bg-accent rounded-md px-2 py-1 text-xs font-mono`

**@提及自动完成**:
- 输入 `@` 时弹出 Agent 列表
- 使用 shadcn/ui `Command` 组件
- 仅列出群组中的 Agent 成员
- 选中后插入 `@AgentName ` 到输入框

**Agent 列表提示**:
- 底部显示当前在线的 Agent 成员
- `text-xs text-muted-foreground`

### 3.3 群组无 Agent

与基础输入相同，但保留 `/new` 按钮。

```

- 位置：消息列表底部，输入区域上方

## 7. 消息加载策略

| 场景 | 行为 |
|------|------|
| 进入会话 | 加载最近 50 条消息 |
| 向上滚动 | 触发 `onScrollTop` 加载更多（每页 50） |
| 实时消息 | WebSocket `message` 事件追加到底部 |
| 缓存 | TanStack Query 按 `group_id` 缓存 |
| 标记已读 | 进入会话 + 滚动到底部 → `PUT /api/groups/:id/read-state` |
