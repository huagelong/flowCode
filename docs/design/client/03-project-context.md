
### Issue 行样式

| 元素 | 样式 |
|------|------|
| ID | `text-xs font-mono text-muted-foreground` |
| 标题 | `text-sm font-medium truncate` |
| 优先级 + 负责人 + 状态 | `text-xs text-muted-foreground`，状态圆点 |
| Hover | `bg-accent/50 rounded px-2` |
| 点击 | 展开为 Issue 详情（替换面板内容） |

### 状态筛选

- 紧凑的 Button Group
- 选中的状态高亮，其他灰色
- 每个 Tab 显示对应 Issue 数量

### Issues Tab 空状态

筛选无结果或项目无 Issue 时：

```
┌─────────────────────────────┐
│                             │
│     [📋 图标 36px]          │
│                             │
│   暂无 Issue                │
│ 通过群组讨论让 Agent 生成   │
│ 或手动创建                  │
│                             │
└─────────────────────────────┘
```

- `text-xs text-muted-foreground`
- 筛选无结果时显示 "该状态下暂无 Issue"

| 属性 | 值 |
|------|------|

### 时间线紧凑样式

- 与 Admin Issue 详情的时间线相同，但更紧凑
- 每项高度更小（`py-1` vs `py-2`）
- 时间省略日期（仅 HH:MM）
- 动作图标更小 (`h-3.5 w-3.5`)

### 操作按钮

根据 Issue 当前状态动态显示（同 Admin Issue 详情）。

---

## 6. 面板切换动效

| 动作 | 动画 |
|------|------|
| 展开面板 | `width: 0 → 320px`，200ms ease-out |
| 折叠面板 | `width: 320px → 0`，150ms ease-in |
| 切换 Tab | 内容 `opacity: 0→1` + `translateX(8→0)`，150ms |
| 进入 Issue 详情 | `translateX(100%) → 0`（覆盖），200ms |
| 返回列表 | `translateX(0) → 100%`，150ms |

---

## 7. 无关联项目

如果群组未关联项目，上下文面板显示：

```
┌─────────────────────────────┐
│                             │
│     [📁 图标 48px]          │
│                             │
│   未关联项目                │
│ 此群组未关联任何项目        │
│ Issue 和 Agent 信息         │
│ 将不会在此显示              │
│                             │
└─────────────────────────────┘
```
