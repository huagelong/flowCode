## 2. 模块详细设计

### 2.1 个人资料区

| 元素 | 样式 | 说明 |
|------|------|------|
| 头像 | Avatar 64px + hover overlay 相机图标 | 点击触发文件选择 |
| 用户名 | `text-sm text-muted-foreground` | 不可编辑 |
| 邮箱 | `text-sm text-muted-foreground` | 不可编辑 |
| GitHub 绑定 | 绿色 Check / 灰色 X + "绑定" 按钮 | OAuth-only 用户不显示密码修改区 |
| 角色 | Badge | 根据当前组织角色显示 |

**头像上传**:
- 支持 JPG/PNG，最大 2MB
- 点击头像 → 选择文件 → 预览裁剪 → 上传
- 上传中显示 Spinner 覆盖

### 2.2 主题选择

三个选项使用 RadioGroup + 自定义样式卡片：

```
┌──────────┐ ┌──────────┐ ┌──────────┐
│   ☀️     │ │   🌙     │ │   💻     │
│  浅色    │ │  深色     │ │ 跟随系统  │
│ (当前)   │ │          │ │          │
└──────────┘ └──────────┘ └──────────┘
```

- 选中态：`border-primary ring-2 ring-primary/20`
- 切换即时生效（`next-themes` `setTheme`）
- 偏好存入 `user_settings` 表

### 2.3 语言选择

- Select 下拉：zh-CN (简体中文) / en-US (English)
- 切换后刷新页面生效
- 调用 `PUT /api/user/settings` 持久化

### 2.4 通知偏好

每项使用 Switch + Label：

```
Issue 被分配时通知         ─────────── ● 开启
```

- Switch 颜色：`data-[state=checked]:bg-primary`
- 对应字段：`notify_issue_assigned`, `notify_agent_completed`, `notify_mention`, `notify_invite`, `notify_email`, `notify_dm`
- 修改即时保存（onChange 调用 API，debounce 500ms）

### 2.5 修改密码

- 仅 email 注册用户可修改（OAuth-only 用户隐藏此区）
- 表单验证：
  - 当前密码：必填
  - 新密码：≥8 字符，包含字母和数字
  - 确认密码：与新密码一致
- 修改成功：Toast + 清空表单
- 修改失败：当前密码字段显示错误 "密码不正确"

### 2.6 退出登录

- 点击后 AlertDialog 确认："确定要退出登录吗？"
- 确认后：清除 JWT → 跳转登录页
