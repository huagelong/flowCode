## 2. 模块详细设计

### 2.1 个人资料区

| 元素 | 样式 | 说明 |
|------|------|------|
| 头像 | Avatar 64px + hover overlay 相机图标 | 点击触发文件选择 |
| 用户名 | `text-sm text-muted-foreground` | 不可编辑 |
| 邮箱 | `text-sm text-muted-foreground` | 不可编辑 |
| GitHub 绑定 | 绿色 Check / 灰色 X + "绑定" 按钮 | 见下方 OAuth 管理流程 |
| 角色 | Badge | 根据当前组织角色显示 |

**头像上传**:
- 支持 JPG/PNG，最大 2MB
- 点击头像 → 选择文件 → 预览裁剪 → 上传
- 上传中显示 Spinner 覆盖
- 裁剪组件：使用 `react-cropper` 或 `react-easy-crop`，1:1 固定比例，输出 128×128px
- 裁剪 Dialog：`max-w-md`，左侧裁剪预览 + 右侧圆形预览（64px）
- 格式错误：Toast "仅支持 JPG/PNG 格式"
- 文件过大：Toast "图片不能超过 2MB"
- 上传失败：Toast "头像上传失败，请重试"

### 2.2 主题选择

三个选项使用 RadioGroup + 自定义样式卡片：

```
┌──────────┐ ┌──────────┐ ┌──────────┐
│   ☀️     │ │   🌙     │ │   💻     │
│  浅色    │ │  深色     │ │ 跟随系统  │
│ (当前)   │ │          │ │          │
└──────────┘ └──────────┘ └──────────┘
```

- 选中态：`border-primary ring-2 ring-primary/20`
- 切换即时生效（`next-themes` `setTheme`）
- 偏好存入 `user_settings` 表

### 2.3 语言选择

- Select 下拉：zh-CN (简体中文) / en-US (English)
- 切换后刷新页面生效
- 调用 `PUT /api/user/settings` 持久化

### 2.4 通知偏好

每项使用 Switch + Label：

```
Issue 被分配时通知         ─────────── ● 开启
```

- Switch 颜色：`data-[state=checked]:bg-primary`
- 对应字段：`notify_issue_assigned`, `notify_agent_completed`, `notify_mention`, `notify_invite`, `notify_email`, `notify_dm`
- 修改即时保存（onChange 调用 API，debounce 500ms）

### 2.5 修改密码

- 仅 email 注册用户可修改（OAuth-only 用户隐藏此区）
- 表单验证：
  - 当前密码：必填
  - 新密码：≥8 字符，包含字母和数字
  - 确认密码：与新密码一致
- 修改成功：Toast + 清空表单
- 修改失败：当前密码字段显示错误 "密码不正确"

**密码强度指示器** (与注册页一致):
```
新密码  ••••••••••
强度    ●●●○○ 中等
需包含数字
```
- 强度等级：弱 `text-red-500` / 中 `text-amber-500` / 强 `text-green-500`
- 规则提示列表：≥8 字符、包含字母、包含数字、包含特殊字符（满足项打 ✓）
- 详见 [shared/00-auth-pages.md](../shared/00-auth-pages.md) 注册页密码强度规范

### 2.5.1 OAuth 账号管理

**绑定流程**:
1. 点击 "绑定" 按钮 → 跳转 GitHub OAuth 授权页
2. 授权成功后回调 → 显示 "✅ 已绑定" + GitHub 用户名
3. 授权失败 → Toast 错误信息

**解绑流程**:
- 已绑定时显示 [解绑] 按钮（`text-destructive`，`variant="ghost" size="sm"`）
- 点击后 AlertDialog 确认："解绑 GitHub 账号后，将无法使用 GitHub 登录，确定要解绑吗？"
- 仅当账号有密码时可解绑（无密码的 OAuth-only 账号禁用解绑按钮 + Tooltip "请先设置密码"）

### 2.5.2 时区设置

位于「外观 & 语言」区域内：

```
│ 时区                                                      │
│ ┌──────────────────────────────────────────────────────┐  │
│ │ Asia/Shanghai (UTC+8)                              ▾ │  │
│ └──────────────────────────────────────────────────────┘  │
```

- Select 下拉：常用时区列表（按 UTC 偏移排序），支持搜索过滤
- 影响时间线时间显示、通知时间格式、Dashboard 日期
- 调用 `PUT /api/user/settings` 持久化

### 2.6 退出登录

- 点击后 AlertDialog 确认："确定要退出登录吗？"
- 确认后：清除 JWT → 跳转登录页
