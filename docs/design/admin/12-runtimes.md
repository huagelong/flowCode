# Admin Runtime 管理

> 路由：`/admin/runtimes`
> API：`/api/admin/runtimes/*`
> 权限：仅 `super_admin`

---

## 1. Runtime 列表页

```
┌──────────────────────────────────────────────────────────────────┐
│ Runtime 管理                              [+ 注册 Runtime]      │
│                                                                  │
│ ┌────────────────────────────────────────────────────────────┐  │
│ │ 名称        │ 显示名       │ 镜像           │ 状态 │ 操作 │  │
│ ├────────────────────────────────────────────────────────────┤  │
│ │ anseragent  │ AnserAgent   │ anserflow/...  │ ● 内置│ ⋯   │  │
│ │ claude-code │ Claude Code  │ anserflow/...  │ ● 启用│ ⋯   │  │
│ └────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────┘
```

### 表格列

| 列 | 宽度 | 说明 |
|------|------|------|
| 名称 | flex | `name` 技术标识符 |
| 显示名 | 140px | `display_name` |
| Docker 镜像 | 200px | `docker_image` 截断 |
| 状态 | 100px | 内置/启用/禁用 Badge |
| 操作 | 60px | 编辑/删除 |

### 状态 Badge

| 状态 | 样式 |
|------|------|
| is_builtin + enabled | `bg-blue-50 text-blue-700` "内置" |
| enabled | `bg-green-50 text-green-700` "启用" |
| disabled | `bg-zinc-50 text-zinc-500` "禁用" |

### 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 技术名称 | Input | ✅ | 2-32 字符，`[a-z0-9-]` |
| 显示名称 | Input | ✅ | 最大 64 字符 |
| 描述 | Textarea (3 行) | — | — |
| Docker 镜像 | Input | ✅ | 有效镜像标签 |
| 执行命令模板 | Textarea | ✅ | 包含 `{workdir}`, `{config}`, `{prompt}` |
| 配置 Schema | JSON 编辑器 | ✅ | JSON Schema 格式 |
| 默认配置 | JSON 编辑器 | ✅ | 与 Schema 兼容的 JSON |
| 默认技能 | 多选 | — | 该 Runtime 的默认 Skill 绑定 |

### JSON 编辑器

- 使用 `Textarea` + JSON 语法验证
- 等宽字体 `font-mono text-sm`
- 失焦时验证 JSON 格式，错误在字段下方显示
- 支持 "格式化" 按钮（自动缩进）

## 4. 删除限制

- 内置 Runtime (`is_builtin=true`) **不可删除**，删除按钮 disabled
- 删除前检查是否有 Agent 在使用该 Runtime
- 如有 Agent 使用，显示 AlertDialog：

```
无法删除 Runtime "anseragent"
当前有 5 个 Agent 正在使用此 Runtime。
请先更改或删除这些 Agent 后再删除。
[确定]
```

- 无 Agent 使用时，正常确认删除流程
