# Admin 项目管理

> 路由：`/admin/projects`
> API：`/api/orgs/:org_id/projects/*`

---

```
┌──────────────────────────────────────────────────────────────────┐
│ 项目管理                                    [+ 创建项目]        │

│ 搜索 [🔍 搜索项目...]                                        │

│ ┌────────────────────────────────────────────────────────────┐  │
│ │ 名称        │ 描述          │ Git 仓库         │ 操作     │  │

### 表格列

| 列 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 名称 | `name` | flex | 可点击进入详情 |
| 描述 | `description` 截断 | 200px | 1 行截断 |
| Git 仓库 | `git_repo_name` + 平台图标 | 200px | GitHub/GitLab 图标 |
| 操作 | DropdownMenu | 60px | 编辑/删除 |

│                                                              │
│                                              [取消] [创建]   │
└──────────────────────────────────────────────────────────────┘
```

### 表单字段

| 字段 | 类型 | 必填 | 验证 |
|------|------|------|------|
| 名称 | Input | ✅ | 2-128 字符 |
| 描述 | Textarea (4 行) | — | 最大 2000 字符 |
| Git 平台 | RadioGroup | ✅ | github/gitea/gitlab/gitee |
| 仓库 URL | Input | ✅ | 有效 URL |
| 认证方式 | RadioGroup | ✅ | http/ssh |
| Token/Key | Password (http) 或 Textarea (ssh) | ✅ | 加密存储 |

### 平台图标

| 平台 | 图标 |
|------|------|
| GitHub | `Github` (lucide) |
| Gitea | Custom SVG |
| GitLab | Custom SVG |
| Gitee | Custom SVG |
