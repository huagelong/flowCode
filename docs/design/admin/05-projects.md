### 设置 Tab

项目级别的运行时与沙箱配置，可覆盖组织默认值。

```
┌──────────────────────────────────────────────────────────────┐
│ 项目设置                                                     │
│                                                              │
│ 运行时数据目录                                               │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ /var/lib/anserflow/projects/1                             │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 项目容器内的数据存储路径，通常无需修改                        │
│                                                              │
│ ── 沙箱资源覆盖 (留空使用组织默认) ──────────────────────── │
│                                                              │
│ 沙箱并发限制                                                 │
│ ┌──────────────┐                                             │
│ │ 3            │                                             │
│ └──────────────┘                                             │
│ 此项目允许同时运行的最大 Agent 数 (0 = 使用组织默认)         │
│                                                              │
│                                              [保存设置]      │
└──────────────────────────────────────────────────────────────┘
```

#### 设置字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| runtime_data_dir | Input (readonly) | 自动生成 | 宿主机上的运行时数据目录 |
| sandbox_concurrency | Number Input | 空 (继承组织默认) | 项目级沙箱并发覆盖 |

- `runtime_data_dir` 为系统自动生成，不可编辑
- `sandbox_concurrency` 留空表示继承组织默认值
- 仅 owner/admin 可编辑
- 保存后立即生效

## 4. 删除项目确认

```
┌──────────────────────────────────────────────────────────────┐
│ 删除项目                                                  ✕  │
│ ──────────────────────────────────────────────────────────── │
│                                                              │
│ ⚠️ 确定要删除 "anserFlow" 项目吗？                          │
│                                                              │
│ 此操作将永久删除项目及其所有 Issue、消息记录和 Agent 绑定。  │
│ 此操作不可撤销。                                             │
│                                                              │
│ 请输入项目名称 "anserFlow" 确认：                            │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │                                                          │ │
│ └──────────────────────────────────────────────────────────┘ │
│                                                              │
│                                        [取消] [确认删除]     │
└──────────────────────────────────────────────────────────────┘
```

- 使用 AlertDialog + 名称输入确认模式（与删除组织一致）
- 确认按钮仅在输入名称完全匹配时可点击
- 确认按钮：`variant="destructive"`
