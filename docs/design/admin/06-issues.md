### 状态 Tab 栏

每个状态显示为一个 Tab，括号内为该状态的 Issue 数量：

```
[backlog 3] [todo 5] [进行中 2] [已暂停 1] [审核中 1] [已完成 12]
```

**Tab 样式**:
- 使用 shadcn/ui `TabsList` + `TabsTrigger`
- 每个 Tab 包含：状态圆点 (8px) + 文字 + 计数 Badge
- 选中态：下方 `border-b-2` + `text-foreground`
- 未选中：`text-muted-foreground`

**颜色对应**:

| Tab | 圆点色 |
|-----|--------|
| backlog | `bg-slate-400` |
| todo | `bg-blue-400` |
| 进行中 | `bg-amber-400` |
| 已暂停 | `bg-orange-400` |
| 审核中 | `bg-purple-400` |
| 已完成 | `bg-green-400` |

### 表格列

| 列 | 宽度 | 说明 |
|------|------|------|
| ☐ | 40px | Checkbox（仅 backlog/todo Tab 可见） |
| ID | 60px | `#42` 格式，可点击展开详情 |
| 标题 | flex | 1 行截断 |
| 优先级 | 80px | P0-P4 Badge |
| 负责人 | 120px | Avatar + 名称，Agent 带 Bot 图标 |
| 创建时间 | 120px | 相对时间 |
| 操作 | 60px | DropdownMenu |

### 批量操作栏

选中 Issue 后，底部浮现批量操作栏：

```
┌──────────────────────────────────────────────────────────────┐
│ 已选择 3 项                    [批量转 Todo] [批量改优先级]    │
└──────────────────────────────────────────────────────────────┘
```

- 仅在 backlog/todo Tab 且有选中项时显示
- 位置：`fixed bottom-4 left-1/2 -translate-x-1/2`
- 样式：`bg-card border shadow-lg rounded-lg px-4 py-3`
- 进入动画：`translateY(20px) → 0`，200ms

```
│ 12:00  📦 系统                         │

└────────────────────────────────────────┘
```

### 时间线事件类型

| 类型 | 图标 | 颜色 | 样式 |
|------|------|------|------|
| status_change | `RefreshCw` | `text-muted-foreground` | 斜体 |
| agent_log | 见下方动作图标 | `text-foreground` | 正常 |
| human_prompt | `MessageSquare` | `text-blue-600 bg-blue-50` | 高亮卡片 |
| system_note | `Info` | `text-muted-foreground` | 斜体 |

### Agent Log 动作图标

| action | 图标 (lucide) |
|--------|---------------|
| generate | `FileCode2` |
| test_pass | `CheckCircle2` |
| test_fail | `XCircle` |
| fix | `Wrench` |
| commit | `GitCommit` |
| create_pr | `GitPullRequest` |
| error | `AlertTriangle` |
| paused | `Pause` |
| default | `FileText` |

### 实时更新

- WebSocket 订阅 `issue:{id}` 频道
- 收到 `agent_log` 事件：追加到时间线底部，自动滚动
- 收到 `status_change` 事件：追加 + 更新顶部状态
- 新条目入场动画：`opacity 0→1` + `translateY(4→0)`，150ms

## 4. 操作按钮 (状态敏感)

| 当前状态 | 可用按钮 | 说明 |
|----------|----------|------|
| backlog | [转为 Todo] | 批量或单个转状态 |
| todo | [转为 Todo] [编辑] | — |
| in_progress | [⏸ 暂停] [⏹ 停止] | 暂停冻结进程，停止终止进程 |
| paused | [▶ 恢复] [⏹ 停止] | 恢复继续执行 |
| in_review | [查看 PR →] | 打开 `pr_url` |
| done | [查看 PR →] | 打开 `pr_url` |

## 5. 人工指令面板

```
┌──────────────────────────────────────────┐
│ 附加指令                                  │
│ ┌──────────────────────────────────────┐ │
│ │ 向 Agent 提供补充指令或修改要求...    │ │
│ │                                      │ │
│ └──────────────────────────────────────┘ │
│                          [发送并重新执行] │
└──────────────────────────────────────────┘
```

- 仅在 `in_progress` / `paused` / `in_review` 状态显示
- Textarea：3 行，`placeholder="向 Agent 提供补充指令或修改要求..."`
- 按钮调用 `POST /api/.../issues/:id/prompt`
- 发送后清空输入框，在时间线添加 `human_prompt` 事件
