### 状态 Tab 栏

每个状态显示为一个 Tab，括号内为该状态的 Issue 数量：

```
[backlog 3] [todo 5] [进行中 2] [已暂停 1] [审核中 1] [已完成 12]
```

**Tab 样式**:
- 使用 shadcn/ui `TabsList` + `TabsTrigger`
- 每个 Tab 包含：状态圆点 (8px) + 文字 + 计数 Badge
- 选中态：下方 `border-b-2` + `text-foreground`
- 未选中：`text-muted-foreground`

**颜色对应**:

| Tab | 圆点色 |
|-----|--------|
| backlog | `bg-slate-400` |
| todo | `bg-blue-400` |
| 进行中 | `bg-amber-400` |
| 已暂停 | `bg-orange-400` |
| 审核中 | `bg-purple-400` |
| 已完成 | `bg-green-400` |

### 表格列

| 列 | 宽度 | 说明 |
|------|------|------|
| ☐ | 40px | Checkbox（仅 backlog/todo Tab 可见） |
| ID | 60px | `#42` 格式，可点击展开详情 |
| 标题 | flex | 1 行截断 |
| 优先级 | 80px | P0-P4 Badge |
| 负责人 | 120px | Avatar + 名称，Agent 带 Bot 图标 |
| 创建时间 | 120px | 相对时间 |
| 操作 | 60px | DropdownMenu |

### 批量操作栏

- 仅在 backlog/todo Tab 且有选中项时显示

- 样式：`bg-card border shadow-lg rounded-lg px-4 py-3`

### 时间线事件类型

### 可展开详情

点击时间线中的 `agent_log` 条目，展开内联详情面板，展示 Agent 执行的完整结构化内容：

```
│ 12:05  🤖 前端Agent                              ▼ 点击展开
│        📄 Generated: src/login.tsx
│        ──────
│  ┌──────────────────────────────────────────────┐
│  │ 📄 生成了 2 个文件                             │
│  │ ─────────────────────────────────────────────│
│  │ ✅ src/components/LoginForm.tsx    +42 -5     │
│  │ ✅ src/hooks/useAuth.ts           +28 new     │
│  │                                 [展开 Diff]   │
│  └──────────────────────────────────────────────┘
│        ──────
│ 12:02  🤖 前端Agent
│        📝 Starting: 读取 Issue 描述...
```

**展开规则**:

| action | 展开后内容 | 组件 |
|--------|-----------|------|
| `generate` | 文件生成卡片（文件列表 + 可展开 DiffViewer） | AgentOutputCard (文件生成) |
| `commit` | Commit 卡片（提交信息 + 哈希 + 文件变更统计 + 分支） | AgentOutputCard (Commit) |
| `create_pr` | PR 创建卡片（标题 + source→target + 外部链接） | AgentOutputCard (PR 创建) |
| `test_pass` | 测试通过卡片（绿色 + 用例列表） | AgentOutputCard (测试通过) |
| `test_fail` | 测试失败卡片（红色 + 失败详情 + 堆栈） | AgentOutputCard (测试失败) |
| `error` | 错误卡片（错误信息 + 堆栈 + 重试按钮） | AgentOutputCard (错误) |
| `fix` | 修复内容摘要 + 文件变更卡片 | AgentOutputCard (文件生成) |
| `paused` / 其他 | 不展开（无结构化详情） | — |

**交互行为**:
- 点击时间线条目行 → 展开内联详情面板（带 `ChevronDown` → `ChevronUp` 图标切换）
- 展开动画：`max-height 0 → auto`，200ms ease-out + `opacity 0 → 1`
- 同一时间只展开一个条目（手风琴模式），展开新条目时自动收起上一个
- 展开区域宽度跟随时间线面板宽度
- 文件生成卡片内的文件项可进一步点击展开 DiffViewer（嵌套展开）
- DiffViewer 完整规范见 [components/08-through-13.md](../components/08-through-13.md)

**展开区域样式**:

| 属性 | 值 |
|------|------|
| 外边距 | `ml-6 mt-1 mb-1`（相对于时间线事件缩进） |
| 背景 | 同 AgentOutputCard 各类型样式 |
| 圆角 | `rounded-lg` |
| 阴影 | `shadow-sm` |
| 边框 | `border` |

### 实时更新

- WebSocket 订阅 `issue:{id}` 频道
- 收到 `agent_log` 事件：追加到时间线底部，自动滚动
- 收到 `status_change` 事件：追加 + 更新顶部状态
- 新条目入场动画：`opacity 0→1` + `translateY(4→0)`，150ms

## 4. 操作按钮 (状态敏感)

| 当前状态 | 可用按钮 | 说明 |
|----------|----------|------|
| backlog | [转为 Todo] | 批量或单个转状态 |
| todo | [转为 Todo] [编辑] | — |
| in_progress | [⏸ 暂停] [⏹ 停止] | 暂停冻结进程，停止终止进程（需确认） |
| paused | [▶ 恢复] [⏹ 停止] | 恢复继续执行 |
| in_review | [查看 PR →] | 打开 `pr_url` |
| done | [查看 PR →] | 打开 `pr_url` |

## 5. 人工指令面板

```
┌──────────────────────────────────────────┐
│ 附加指令                                  │
│ ┌──────────────────────────────────────┐ │
│ │ 向 Agent 提供补充指令或修改要求...    │ │
│ │                                      │ │
│ └──────────────────────────────────────┘ │
│                          [发送并重新执行] │
└──────────────────────────────────────────┘
```

- 仅在 `in_progress` / `paused` / `in_review` 状态显示
- Textarea：3 行，`placeholder="向 Agent 提供补充指令或修改要求..."`
- 按钮调用 `POST /api/orgs/:org_id/projects/:project_id/issues/:id/prompt`
- 发送后清空输入框，在时间线添加 `human_prompt` 事件

## 7. 危险操作确认

### 停止执行确认

点击 [⏹ 停止] 时弹出确认：

```
┌──────────────────────────────────────────────────────────────┐
│ 停止执行                                                  ✕  │
│ ──────────────────────────────────────────────────────────── │
│                                                              │
│ ⚠️ 确定要停止 Issue #42 的执行吗？                          │
│                                                              │
│ Agent 正在执行的任务将被强制终止，已生成的文件和提交不受影响。│
│                                                              │
│                                        [取消] [确认停止]     │
└──────────────────────────────────────────────────────────────┘
```

- 使用 AlertDialog
- 确认按钮：`variant="destructive"`
- 停止后 Issue 状态变为 `todo`（保留已完成的成果）

### 删除 Issue 确认

```
┌──────────────────────────────────────────────────────────────┐
│ 删除 Issue                                                ✕  │
│ ──────────────────────────────────────────────────────────── │
│                                                              │
│ ⚠️ 确定要删除 Issue #42 "修复登录Bug" 吗？                  │
│                                                              │
│ 此操作将永久删除该 Issue 及其所有时间线记录和 Token 用量数据。│
│                                                              │
│                                        [取消] [确认删除]     │
└──────────────────────────────────────────────────────────────┘
```

- 使用 AlertDialog
- 如 Issue 状态为 `in_progress`，额外提示 "Agent 正在执行，请先停止任务"
- 确认按钮：`variant="destructive"`
