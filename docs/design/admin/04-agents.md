### 表格列

| 列 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 头像 | Agent Avatar (32px，带 Bot 图标) | 48px | — |
| 名称 | `name` | flex | 可点击进入详情 |
| 角色标签 | `role_label` Badge | 120px | 颜色见 [设计令牌](../01-design-tokens.md) |
| 运行时 | `runtimes.display_name` | 120px | — |
| 状态 | `enabled` 开关 | 80px | Switch toggle |
| Token | 近 7 天 token 用量 | 100px | 链接到用量详情 |
| 操作 | DropdownMenu | 60px | 编辑/删除/日志 |

### 搜索 & 筛选

- **搜索**: 实时搜索名称/角色标签，debounce 300ms
- **运行时筛选**: Dropdown，列出所有可用 Runtime
- **状态筛选**: 启用/禁用/全部

### 操作菜单 (⋯)

| 执行日志 | 所有成员 | `ScrollText` |

### 2.2 表单字段

#### 基本信息区

| 字段 | 类型 | 必填 | 验证 |
|------|------|------|------|
| 名称 | Input | ✅ | 2-64 字符，组织内唯一 |
| 角色标签 | Combobox (可输入 + 下拉) | ✅ | 最大 64 字符 |
| 系统提示词 | Textarea (8 行) | ✅ | 10-10000 字符 |
| 启用状态 | Switch | — | 默认开启 |

**角色标签预设选项**:
CEO, CTO, Frontend, Backend, DevOps, QA, Designer, Custom (手动输入)

#### 运行时配置区

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 运行时 | Select | ✅ | 从 `runtimes` 表获取 |
| Provider | Select | ✅ | openai / anthropic / google / deepseek |
| Model | Input | ✅ | 如 gpt-4o, claude-3.5-sonnet |
| API Key | Password Input | ✅ | AES-256 加密存储，显示 `sk-****` |
| 最大迭代次数 | Number Input | — | 默认 20，范围 1-100 |
| 深度思考 | Switch | — | 默认开启 |

**动态表单**: 当运行时变化时，`config_schema` 字段驱动渲染额外配置字段（使用 FormBuilder 组件）。

#### 技能绑定区

| 列 | 说明 |
|------|------|
| 勾选 | Checkbox，绑定/解绑 |
| 名称 | Skill 名称 |
| 来源标签 | Badge 标注 "运行时默认" 或 "组织级" |
| 启用开关 | Switch，仅已勾选的可操作 |

- 运行时默认 Skills 默认勾选
- 组织级 Skills 可选勾选

### 2.3 表单验证

使用 Zod schema:

```typescript
const agentSchema = z.object({
  name: z.string().min(2).max(64),
  role_label: z.string().min(1).max(64),
  system_prompt: z.string().min(10).max(10000),
  runtime_id: z.number().int().positive(),
  runtime_config: z.object({
    provider: z.enum(["openai", "anthropic", "google", "deepseek"]),
    model: z.string().min(1),
    api_key: z.string().min(1),
    max_iterations: z.number().int().min(1).max(100).default(20),
    thinking: z.boolean().default(true),
  }),
  enabled: z.boolean().default(true),
  skill_ids: z.array(z.object({
    skill_id: z.number(),
    enabled: z.boolean(),
  })),
});
```

## 4. 删除确认

与组织删除类似，使用 AlertDialog:

```
确定要删除 Agent "前端Agent" 吗？
- 该 Agent 的所有执行记录将被保留
- 绑定的技能不会被删除
- 正在执行的任务将被终止

[取消]  [确认删除]
```

## 5. 交互状态

| 操作 | 加载态 | 成功态 | 失败态 |
|------|--------|--------|--------|
| 创建 Agent | 保存按钮 Spinner | Toast + 跳转详情 | Toast + 保持表单 |
| 编辑 Agent | 保存按钮 Spinner | Toast "已保存" | Toast 错误 |
| 启用/禁用 | Switch 动画中 | Toast + 状态更新 | Toast + 回滚 |
| 删除 Agent | 按钮变 Spinner | Toast + 返回列表 | Toast 错误 |
