**成员表格列**:

| 列 | 说明 |
|------|------|
| 头像 | Avatar 组件，32px |
| 用户名 | `username` |
| 邮箱 | `email`，无邮箱显示 "—" |

| 角色 | 说明 | 颜色 |
|------|------|------|
| owner | 所有者（唯一，不可删除） | `bg-primary text-primary-foreground` |
| admin | 管理员 | `bg-secondary text-secondary-foreground` |
| member | 成员 | `bg-muted text-muted-foreground` |

## 4. 邀请成员 Dialog

```
┌──────────────────────────────────────┐
│ 邀请成员                          ✕  │
│ ──────────────────────────────────── │
│                                      │
│ 邀请方式                             │
│ ○ 邮箱邀请   ○ 链接邀请              │
│                                      │
│ ── 邮箱邀请 ──────────────────────── │
│                                      │
│ 邮箱地址 *                           │
│ ┌──────────────────────────────────┐ │
│ │ colleague@example.com            │ │
│ └──────────────────────────────────┘ │
│                                      │
│ 角色 *                               │
│ ┌────────────┐                       │
│ │ 成员      ▾│                       │
│ └────────────┘                       │
│                                      │
│           [取消] [发送邀请]          │
│                                      │
│ ── 链接邀请 ──────────────────────── │
│                                      │
│ 链接有效期                           │
│ ┌────────────┐                       │
│ │ 7 天      ▾│                       │
│ └────────────┘                       │
│                                      │
│ 最大使用次数                         │
│ ┌────────────┐                       │
│ │ 0 (无限)   │                       │
│ └────────────┘                       │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ https://app.anserflow/invite/xxx │📋│
│ └──────────────────────────────────┘ │
│                                      │
│           [生成链接]                 │
└──────────────────────────────────────┘
```

### 邮箱邀请

- 输入邮箱 + 选择角色 (admin/member)
- 点击"发送邀请" → 后端发邮件 + 存 `invitations` 表
- 成功提示：Sonner toast "邀请已发送"

### 链接邀请

- 选择有效期 (7天/30天/永久)
- 设置最大使用次数 (0=无限)
- 点击"生成链接" → 显示链接 + 复制按钮
- 复制成功提示：Sonner toast "链接已复制到剪贴板"

## 7. 交互状态

| 操作 | 加载态 | 成功态 | 失败态 |
|------|--------|--------|--------|
| 创建组织 | 按钮显示 Spinner | Toast + 跳转详情页 | Toast 错误信息 |
| 邀请成员 | 按钮显示 Spinner | Toast "已发送" | Toast "邮箱格式错误" |
| 修改角色 | Select 变灰 | Toast "已更新" | Toast + 回滚值 |
| 删除成员 | 按钮变灰 | Toast + 移除行 | Toast 错误 |
| 删除组织 | 按钮显示 Spinner | Toast + 跳转列表 | Toast 错误 |
