### 2.2 技能定义编辑器

**左半部分**: 代码编辑区
- 使用 `Textarea` 或集成 `CodeMirror` / `Monaco Editor`
- 等宽字体 `font-mono text-sm`
- 行号显示
- 暗色背景 `bg-zinc-900 text-zinc-100`

**右半部分**: 实时预览
- 解析 YAML frontmatter 渲染元数据表格
- 解析 Markdown body 渲染为 HTML
- 预览区：`prose prose-sm max-w-none`

### 2.3 表单字段

| 字段 | 类型 | 必填 | 验证 |
|------|------|------|------|
| 名称 | Input | ✅ | 2-64 字符，组织内唯一 |
| 描述 | Input | — | 最大 500 字符 |
| 定义 | 代码编辑器 | ✅ | 必须包含有效 YAML frontmatter |
| 启用状态 | Switch | — | 默认开启 |

### 2.4 YAML Frontmatter 验证

必需字段：`name`
可选字段：`version`, `success_rate`, `use_count`, `last_used`, `tags`

验证失败时在编辑器下方显示错误提示：
```
⚠️ YAML 解析错误: "name" 字段为必填项
```

```
┌──────────────────────────────────────────────────────────────┐
│ 导入技能 (ZIP)                                            ✕  │

│                                                              │
│ ┌─ 导入预览 ──────────────────────────────────────────────┐  │

│ │                                                          │  │

│ │ ☑ api-crud/SKILL.md      ✓ 有效                        │  │
│ │ ☐ broken/SKILL.md        ✗ 格式错误: 缺少 name 字段    │  │
│ └──────────────────────────────────────────────────────────┘  │
│                                                              │
│                                         [取消] [导入 (2 项)] │
└──────────────────────────────────────────────────────────────┘
```

### 导入流程

1. 拖拽或选择 ZIP 文件
2. 前端解压验证（检查 SKILL.md 存在性）
3. 显示预览列表（文件名 + 验证状态）
4. 用户勾选要导入的 Skills
5. 点击"导入" → `POST /api/orgs/:org_id/skills/import/zip`
6. 成功提示 + 跳转到 Skill 列表

### 拖拽区域样式

| 状态 | 样式 |
|------|------|
| 默认 | `border-2 border-dashed border-muted-foreground/25 rounded-lg` |
| 拖拽悬停 | `border-primary bg-primary/5` |
| 上传中 | 显示进度条 |
| 错误 | `border-destructive bg-destructive/5` |
