# 错误页面

> 404 / 403 / 500 等错误页面的统一设计

---

## 1. 404 Not Found

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                      404                                 │
│                                                          │
│                  页面未找到                               │
│                                                          │
│        你访问的页面不存在或已被移除                        │
│                                                          │
│              [返回首页]                                   │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 样式

| 元素 | 样式 |
|------|------|
| 页面 | 全屏居中 `flex flex-col items-center justify-center min-h-screen` |
| 错误码 | `text-8xl font-bold text-muted-foreground/20` |
| 标题 | `text-2xl font-semibold mt-4` |
| 描述 | `text-sm text-muted-foreground mt-2` |
| 按钮 | `mt-6 variant="outline"` |
| 背景 | `bg-background` |

### 返回首页行为

| 端 | 跳转 |
|------|------|
| Admin | `/admin/dashboard` |
| Client | `/client/chat` |

## 2. 403 Forbidden

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    🔒                                    │
│                                                          │
│                  没有权限                                 │
│                                                          │
│        你没有访问此页面的权限                             │
│        请联系组织管理员获取权限                            │
│                                                          │
│              [返回首页]                                   │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 图标：`Lock` (lucide)，`h-16 w-16 text-muted-foreground`
- 错误码可不显示（403 语义更明确用图标）

## 3. 500 Internal Error

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    ⚠️                                    │
│                                                          │
│                  服务器错误                               │
│                                                          │
│        服务器遇到了一个错误                               │
│        请稍后重试                                        │
│                                                          │
│        [返回首页]  [重试]                                │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 图标：`AlertTriangle`，`h-16 w-16 text-destructive`
- 额外提供"重试"按钮，刷新当前页面

## 4. 网络离线

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    📡                                    │
│                                                          │
│                  网络已断开                               │
│                                                          │
│        请检查网络连接后重试                               │
│                                                          │
│              [重试]                                      │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 图标：`WifiOff`，`h-16 w-16 text-muted-foreground`
- 全局 Toast 检测网络状态变化
- 网络恢复后自动消失

## 5. Session 过期

JWT 过期时，弹出 AlertDialog：

```
┌──────────────────────────────────────┐
│                                      │
│  会话已过期                          │
│                                      │
│  你的登录已过期，请重新登录。         │
│                                      │
│              [重新登录]               │
│                                      │
└──────────────────────────────────────┘
```

- 无取消按钮，必须重新登录
- 点击后跳转登录页
- 由 Axios 拦截器 401 响应触发
