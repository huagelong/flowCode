# 共享认证页面

> 路由：`/admin/login`, `/admin/register`, `/client/login`, `/client/register`
> API：`/api/auth/*`

---

```
│                    │  │           │  │                    │
│                    │  └───────────┘  │                    │
│                    │                 │                    │
│                    │  密码           │                    │
│                    │  ┌───────────┐  │                    │
│                    │  │           │  │                    │
```

### 样式参数

| 属性 | 值 |
|------|------|
| 页面背景 | `bg-background` |
| 卡片 | `max-w-sm w-full mx-auto bg-card border rounded-xl shadow-sm p-8` |
| Logo | 自定义 SVG，`h-10 w-10` |
| 品牌名 | `text-xl font-bold` |
| 标签 | `text-sm font-medium` |
| 输入框 | 标准 Input |
| 登录按钮 | `w-full variant="default" h-10` |
| GitHub 按钮 | `w-full variant="outline" h-10` |
| 分隔线 | `relative` + `text-xs text-muted-foreground` |

### 表单字段

| 字段 | 类型 | 验证 |
|------|------|------|
| 邮箱 | Input type="email" | 必填，有效邮箱格式 |
| 密码 | Password Input | 必填，≥6 字符 |
| 记住我 | Checkbox | 可选，控制 JWT 过期时间 |

### GitHub 按钮

```
┌──────────────────────────────────────┐
│  [GitHub 图标]  使用 GitHub 登录      │
└──────────────────────────────────────┘
```

- `variant="outline"`
- 图标：`Github` (lucide)，`mr-2 h-4 w-4`
- 点击后跳转 `GET /api/auth/github/login` → 302 GitHub

### 错误状态

| 场景 | 显示 |
|------|------|
| 邮箱不存在 | "账号不存在" (邮箱字段下) |
| 密码错误 | "密码不正确" (密码字段下) |
| OAuth 失败 | 顶部 Alert "GitHub 登录失败，请重试" |
| 网络错误 | Sonner toast "网络错误，请检查连接" |
| 账号被禁用 | AlertDialog "账号已被禁用" |

### 加载状态

- 提交时按钮显示 Spinner + "登录中..."
- GitHub 按钮提交后禁用
- 表单字段全部禁用


### 表单字段

| 字段 | 类型 | 验证 |
|------|------|------|
| 用户名 | Input | 必填，2-64 字符，`[a-zA-Z0-9_-]`，唯一 |
| 邮箱 | Input type="email" | 必填，有效邮箱，唯一 |
| 密码 | Password Input | 必填，≥8 字符，含字母和数字 |
| 确认密码 | Password Input | 必填，与密码一致 |

### 密码强度指示器

```
●●●○○  中等强度
```

| 等级 | 圆点 | 颜色 | 条件 |
|------|------|------|------|
| 弱 | ●○○○○ | `bg-red-500` | < 8 字符 |
| 一般 | ●●○○○ | `bg-orange-500` | ≥ 8 字符 |
| 中等 | ●●●○○ | `bg-amber-500` | ≥ 8 + 字母+数字 |
| 强 | ●●●●○ | `bg-green-500` | ≥ 12 + 字母+数字+特殊字符 |
| 很强 | ●●●●● | `bg-emerald-500` | ≥ 16 + 全部 |

## 3. OAuth 回调页

GitHub OAuth 回调时显示加载态：

```
┌──────────────────────────────────────┐
│                                      │
│          [Loader2 spinning]          │
│                                      │
│        正在登录，请稍候...           │
│                                      │
└──────────────────────────────────────┘
```

- 全屏居中
- Spinner + 文字
- 成功后跳转目标页面
- 失败显示错误信息 + 重试按钮

| 属性 | Admin | Client |
|------|-------|--------|
