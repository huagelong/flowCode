## 2. 加载状态

### 2.1 全页加载 (初始)

| 场景 | 表现 |
|------|------|
| 首次进入页面 | Skeleton 骨架屏 |
| 路由切换 | 页面淡入动画 (opacity 0→1, 150ms) |
| 刷新 | Skeleton |

### 2.2 局部刷新 (轮询/推送)

| 场景 | 表现 |
|------|------|
| TanStack Query refetch | 静默更新（无 loading），数据到后替换 |
| WebSocket 推送 | 直接增量追加/更新，无 loading |
| 手动刷新 | 顶部进度条 `h-0.5 bg-primary animate-pulse` |

### 2.3 操作加载

| 操作 | 按钮 | 页面 |
|------|------|------|
| 保存/创建 | Spinner + "保存中..." | 无变化 |
| 删除 | Spinner + "删除中..." | 无变化 |
| 发送消息 | 禁用输入 + Spinner | 消息追加到列表 |
| 搜索 | 输入框内 Spinner | 列表区域 Skeleton |

### 2.4 按钮加载态

```tsx
<Button disabled={isLoading}>
  {isLoading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
  {isLoading ? "处理中..." : "保存"}
</Button>
```

## 3. 过渡动画

### 3.1 页面切换

```tsx
// Next.js page transition via Framer Motion
<motion.div
  initial={{ opacity: 0, y: 8 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.15 }}
>
  {children}
</motion.div>
```

### 3.2 列表项入场

```tsx
// 交错入场
<motion.div
  initial={{ opacity: 0, x: -8 }}
  animate={{ opacity: 1, x: 0 }}
  transition={{ delay: index * 0.03, duration: 0.15 }}
>
```

### 3.3 展开/折叠

```tsx
// 使用 Radix UI Collapse 或 Framer Motion
<motion.div
  initial={{ height: 0, opacity: 0 }}
  animate={{ height: "auto", opacity: 1 }}
  exit={{ height: 0, opacity: 0 }}
  transition={{ duration: 0.2 }}
>
```

### 3.4 禁用动画 (a11y)

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

用户系统设置减少动画时，所有动画立即完成。

## 4. 错误态

### 4.1 全页错误

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    ⚠️                                    │
│                                                          │
│              加载失败                                    │
│                                                          │
│        请检查网络连接后重试                               │
│                                                          │
│              [重试]                                      │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 使用 `error.tsx` boundary 捕获
- 提供"重试"按钮重新触发请求

### 4.2 表格数据为空

使用 EmptyState 组件（见 [components/14-through-20.md](../components/14-through-20.md)）。

### 4.3 表单提交失败

- 错误信息显示在表单顶部：`bg-destructive/10 text-destructive rounded-md px-4 py-3 text-sm`
- 或显示在对应字段下方
- Toast 补充通知
