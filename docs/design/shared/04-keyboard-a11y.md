# 键盘快捷键 & 无障碍参考

> Admin 和 Client 端的键盘操作规范

---

## 1. 全局快捷键

### Admin 端

| 快捷键 | 功能 | 上下文 |
|--------|------|--------|
| `Ctrl/Cmd + K` | 打开全局搜索 Command Palette | 全局 |
| `Ctrl/Cmd + /` | 打开快捷键帮助面板 | 全局 |
| `Ctrl/Cmd + \` | 切换侧边栏折叠/展开 | 全局 |
| `Escape` | 关闭 Dialog / Popover / Command Palette | 弹层打开时 |

### Client 端

| 快捷键 | 功能 | 上下文 |
|--------|------|--------|
| `Ctrl/Cmd + K` | 打开全局搜索 | 全局 |
| `Ctrl/Cmd + /` | 打开快捷键帮助面板 | 全局 |
| `Ctrl/Cmd + N` | 新建会话 | 聊天视图 |
| `Ctrl/Cmd + [` | 切换到上一个会话 | 聊天视图 |
| `Ctrl/Cmd + ]` | 切换到下一个会话 | 聊天视图 |
| `Alt + ↑` | 会话列表上移 | 聊天视图 |
| `Alt + ↓` | 会话列表下移 | 聊天视图 |
| `Escape` | 关闭上下文面板 / 取消搜索 | 全局 |

### 聊天输入

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift + Enter` | 换行 |
| `↑` (空输入框) | 编辑上一条发送的消息 (Phase 2) |

### @提及

| 快捷键 | 功能 |
|--------|------|
| `@` | 打开 Agent 列表 |
| `↑ / ↓` | 列表内导航 |
| `Enter` | 选中 Agent |
| `Escape` | 关闭列表 |

## 2. 焦点管理

### Dialog 打开时
- 焦点自动移到 Dialog 内第一个可聚焦元素
- Tab 键在 Dialog 内循环 (focus trap)
- 关闭后焦点回到触发按钮

### 路由切换
- 焦点移到页面主内容区域 (`<main>`)
- 使用 `role="main"` 标记

### 聊天窗口
- 新消息到达时不抢焦点
- 发送消息后焦点保留在输入框
- Tab 键可以导航到消息列表中的可交互元素

## 3. 屏幕阅读器 (Screen Reader)

### Landmark Roles

```html
<nav aria-label="主导航">...</nav>
<main aria-label="聊天窗口">...</main>
<aside aria-label="项目上下文">...</aside>
```

### Live Regions

| 区域 | 属性 | 用途 |
|------|------|------|
| 未读消息计数 | `aria-live="polite"` | 数量变化时播报 |
| 聊天消息列表 | `role="log" aria-live="polite"` | 新消息播报 |
| Timeline 事件 | `role="log" aria-live="polite"` | 新事件播报 |
| Toast 通知 | `role="status"` | 操作结果播报 |
| 打字指示器 | `aria-live="polite"` | "Agent 正在输入" |

### 消息可访问性

```html
<div role="article" aria-label="张三 14:30 说：我们需要优化登录页面">
  ...
</div>
```

- 每条消息标记 `role="article"`
- 包含发送者、时间、内容
- Agent 消息标注 "Agent CTO 说："

### Issue 状态播报

状态变化时通过 `aria-live` 播报：
```
"Issue #42 状态从 进行中 变更为 审核中"
```

## 4. 颜色对比度

| 场景 | 最小对比度 | 标准 |
|------|-----------|------|
| 正文文字 | 4.5:1 | WCAG AA |
| 大文字 (≥18px) | 3:1 | WCAG AA |
| 交互元素边框 | 3:1 | WCAG AA |
| 状态色 + 文字 | 4.5:1 | WCAG AA |

**不依赖颜色唯一传达信息**:
- Issue 状态：颜色 + 文字标签 + 图标
- 优先级：颜色 + 文字 (P0-P4)
- 错误：颜色 + 图标 + 文字描述

## 5. 触摸目标 (Touch Targets)

移动端最小触摸目标：

| 元素 | 最小尺寸 |
|------|----------|
| 按钮 | 44 × 44px |
| 导航项 | 44 × 44px |
| 消息气泡可点击区域 | 44px 高 |
| Checkbox / Radio | 44 × 44px |
| 列表项 | 48px 高 |

---

## 6. 跳过导航链接

```html
<a href="#main-content" class="sr-only focus:not-sr-only">
  跳到主要内容
</a>
```

- 页面首个可聚焦元素
- 仅在 Tab 聚焦时显示
- 跳转到 `<main>` 区域

## 7. 快捷键帮助面板

`Ctrl/Cmd + /` 或 `?` 打开快捷键帮助面板，展示所有可用快捷键：

```
┌──────────────────────────────────────────────────────────┐
│ 键盘快捷键                                            ✕  │
│ ──────────────────────────────────────────────────────── │
│                                                          │
│ 全局                                                     │
│ ──────────────────────────────────────────────────────── │
│ Ctrl+K        全局搜索                                   │
│ Ctrl+/        显示快捷键帮助                             │
│ Esc           关闭弹层                                   │
│                                                          │
│ 聊天                                                     │
│ ──────────────────────────────────────────────────────── │
│ Enter         发送消息                                   │
│ Shift+Enter   换行                                       │
│ Ctrl+N        新建会话                                   │
│ Ctrl+]/[      上/下一个会话                              │
│ @             打开 Agent 提及列表                        │
│                                                          │
│ 导航                                                     │
│ ──────────────────────────────────────────────────────── │
│ Ctrl+\        切换侧边栏 (Admin)                         │
│ Alt+↑/↓       会话列表导航 (Client)                      │
│                                                          │
│                    按 Esc 关闭此面板                      │
└──────────────────────────────────────────────────────────┘
```

- 使用 shadcn/ui `Dialog` 组件，`className="max-w-md"`
- 快捷键列：`kbd` 标签，`bg-muted rounded px-1.5 py-0.5 text-xs font-mono`
- 功能列：`text-sm`
- 分组标题：`text-xs font-semibold text-muted-foreground uppercase`
- 仅显示当前端（Admin / Client）可用的快捷键
