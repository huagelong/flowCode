# 邀请接受页

> 路由：`/invite/:token` (公开页面，无需登录)
> API：`GET /invite/:token`

---

## 1. 已登录用户

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    🎫                                    │
│                                                          │
│              加入 "Acme Corp"                            │
│                                                          │
│        张三 邀请你加入 Acme Corp 组织                    │
│        角色: 成员                                        │
│                                                          │
│        [接受邀请]  [拒绝]                                │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 样式

| 元素 | 样式 |
|------|------|
| 图标 | `Ticket` (lucide)，`h-16 w-16 text-primary` |
| 组织名 | `text-2xl font-bold` |
| 邀请人 | `text-sm text-muted-foreground` |
| 角色 Badge | 标准 Badge |
| 接受按钮 | `variant="default" size="lg"` |
| 拒绝按钮 | `variant="ghost"` |

### 处理流程

1. 访问 `/invite/:token`
2. 后端校验 token 有效性
3. 已登录 → 显示邀请详情
4. 未登录 → 跳转登录页，登录后自动回到此页

---

```
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 图标：`XCircle`，`h-16 w-16 text-destructive`

---

## 3. 未登录跳转

未登录用户访问邀请链接：

1. 跳转 `/admin/login?redirect=/invite/:token` (或 client)
2. 登录成功后自动跳回 `/invite/:token`
3. 如果是新用户，跳转注册页 + redirect 参数
