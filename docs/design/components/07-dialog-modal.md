# Dialog / AlertDialog 对话框

> 基于 shadcn/ui `Dialog` + `AlertDialog`

---

## 1. Dialog (标准对话框)

用于创建/编辑表单等。

```
┌──────────────────────────────────────┐
│ 标题                              ✕  │
│ ──────────────────────────────────── │
│                                      │
│ (表单内容)                           │
│                                      │
│ ──────────────────────────────────── │
│                     [取消]  [确认]   │
└──────────────────────────────────────┘
```

### 样式参数

| 属性 | 值 |
|------|------|
| 最大宽度 | `max-w-lg` (512px)，表单可用 `max-w-2xl` (672px) |
| 背景 | `bg-card` |
| 圆角 | `rounded-lg` |
| 阴影 | `shadow-lg` |
| 遮罩 | `bg-black/80`，点击关闭 |
| 关闭按钮 | 右上角 `✕`，`variant="ghost" size="icon"` |
| 标题 | `text-lg font-semibold` |
| 内容区 | 可滚动 `max-h-[70vh] overflow-y-auto` |
| 底部按钮区 | `flex justify-end gap-2 pt-4` |

### 动画

```tsx
const dialogVariants = {
  initial: { opacity: 0, scale: 0.95 },
  animate: { opacity: 1, scale: 1 },
  exit: { opacity: 0, scale: 0.95 },
  transition: { duration: 0.15 },
};
```

### 无障碍

- 自动焦点捕获 (focus trap)
- `Escape` 关闭
- 打开时背景不可滚动
- `aria-labelledby` / `aria-describedby`

## 2. AlertDialog (确认对话框)

用于删除确认等危险操作。

```
┌──────────────────────────────────────┐
│                                      │
│  ⚠️ 确定要删除吗？                   │
│                                      │
│  此操作不可撤销，相关数据将被         │
│  永久删除。                          │
│                                      │
│              [取消]  [确认删除]       │
│                                      │
└──────────────────────────────────────┘
```

### 样式

| 属性 | 值 |
|------|------|
| 最大宽度 | `max-w-md` (448px) |
| 取消按钮 | `variant="outline"` |
| 确认按钮 | `variant="destructive"` |
| 图标 | 警告 `AlertTriangle text-destructive` |

### 变体

| 场景 | 图标 | 标题 | 按钮文字 |
|------|------|------|----------|
| 删除 | `Trash2` / `AlertTriangle` | "确定要删除 {名称} 吗？" | "确认删除" |
| 退出 | `LogOut` | "确定要退出登录吗？" | "退出" |
| 重置 | `RotateCcw` | "确定要重置所有配置吗？" | "确认重置" |
| 离开群组 | `LogOut` | "确定要离开群组吗？" | "离开" |

## 3. 确认输入型 Dialog

高危操作需要输入确认文字：

```
┌──────────────────────────────────────┐
│ ⚠️ 删除组织                          │
│ ──────────────────────────────────── │
│                                      │
│ 确定要删除 "My Organization" 吗？    │
│ 此操作不可撤销。                     │
│                                      │
│ 请输入 "My Organization" 以确认：    │
│ ┌──────────────────────────────────┐ │
│ │                                  │ │
│ └──────────────────────────────────┘ │
│                                      │
│              [取消]  [确认删除]       │
└──────────────────────────────────────┘
```

- 确认按钮初始 `disabled`
- 输入文字与目标文字匹配后启用
- 实时比较，`onChange` 触发

## 4. Sheet (侧滑面板)

用于 Client 端上下文面板和移动端全屏面板。

### 右侧 Sheet

```
                           ┌────────────────────────┐
       背景内容区          │ Sheet Header           │
       (遮罩覆盖)          │ ────────────────────── │
                           │ Sheet Content          │
                           │                        │
                           │                        │
                           │                        │
                           │                        │
                           │ ────────────────────── │
                           │ Sheet Footer           │
                           └────────────────────────┘
```

| 属性 | 值 |
|------|------|
| 宽度 | `w-[480px]` (Admin Issue 详情) / `w-80` (Client 上下文) |
| 遮罩 | `bg-black/50` |
| 动画 | `translateX(100%) → 0`，200ms ease-out |

### 动画

```tsx
const sheetVariants = {
  initial: { x: "100%" },
  animate: { x: 0 },
  exit: { x: "100%" },
  transition: { duration: 0.2, ease: [0.4, 0, 0.2, 1] },
};
```
