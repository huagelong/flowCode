### 8.4 核心接口

```go
// memory/manager.go
type MemoryManager struct {
    store     WikiStore           // Markdown 文件读写
    retriever MemoryRetriever     // 检索器
}

// Recall 检索记忆（按层级路由）
func (m *MemoryManager) Recall(ctx context.Context, req RecallRequest) ([]Memory, error)

// Store 存储记忆（根据层级写入对应文件）
func (m *MemoryManager) Store(ctx context.Context, mem Memory) error

// SummarizeAndArchive 将会话总结归档到 L4
func (m *MemoryManager) SummarizeAndArchive(ctx context.Context, sessionID string) error

// UpdateIndex 同步更新 L1 索引
func (m *MemoryManager) UpdateIndex(ctx context.Context, projectID uint) error

type RecallRequest struct {
    AgentID   uint
    ProjectID uint
    Query     string            // 检索查询
    Layers    []MemoryLayer     // 指定检索层级
    Limit     int               // 返回条数
}

type Memory struct {
    ID        string
    Layer     MemoryLayer       // L0 / L1 / L2 / L3 / L4
    Content   string
    FilePath  string            // 来源 Markdown 文件路径
    Tags      []string
    Source    string            // session_id / issue_id / manual
    CreatedAt time.Time
}

type MemoryLayer string

const (
    LayerL0 MemoryLayer = "L0"  // 元规则
    LayerL1 MemoryLayer = "L1"  // 记忆索引
    LayerL2 MemoryLayer = "L2"  // 全局事实
    LayerL3 MemoryLayer = "L3"  // 任务 Skills / SOPs
    LayerL4 MemoryLayer = "L4"  // 会话归档
)
```

**并发写入安全策略**：

L2~L4 的记忆存储在 Markdown 文件中，多 Agent 同时写入同一文件时需保证数据完整性：

```go
// memory/writer.go — 安全写入器

type SafeWriter struct {
    mu    sync.Mutex         // 进程内互斥（单实例）
    redis *redis.Client      // 分布式锁（多实例）
}

// WriteAtomic 原子写入：写临时文件 → rename 替换
func (w *SafeWriter) WriteAtomic(ctx context.Context, filePath string, content []byte) error {
    // 1. 获取文件级分布式锁
    lockKey := fmt.Sprintf("memory_lock:%s", filePath)
    lock := w.redis.SetNX(ctx, lockKey, "locked", 30*time.Second)
    if !lock.Val() {
        return fmt.Errorf("文件 %s 正在被其他 Agent 写入", filePath)
    }
    defer w.redis.Del(ctx, lockKey)

    // 2. 写入临时文件
    tmpPath := filePath + ".tmp"
    if err := os.WriteFile(tmpPath, content, 0644); err != nil {
        return err
    }

    // 3. 原子替换（rename 是原子操作）
    return os.Rename(tmpPath, filePath)
}
```

| 层级 | 并发风险 | 保护策略 |
|------|---------|---------|
| L0 元规则 | 低（仅管理员修改） | 进程内 Mutex |
| L1 索引 | 中（多 Agent 触发更新） | 分布式锁 + WriteAtomic |
| L2 全局事实 | 中（多 Agent 写入不同条目） | 文件级锁 |
| L3 Skills | **高**（多 Agent 可能改进同一 Skill） | 分布式锁 + 版本号 CAS |
| L4 会话归档 | 低（每个会话独立文件） | 文件级锁 |
