### 8.6 更新频率与权限

| 层级 | 更新频率 | 谁能写 | 自动/人工 |
|------|---------|--------|----------|
| L0 元规则 | 极低（月度/季度） | 人工 | 人工 |
| L1 索引 | 跟随 L2-L4 更新 | Agent 自动 | 自动 |
| L2 全局事实 | 低（周度） | Agent 积累 + 人工审核 | 半自动 |
| L3 Skills | 中（每次执行后评估） | Agent 自动生成 + 自改进 | 自动 |
| L4 会话归档 | 高（每次任务完成） | Agent 自动归档 | 自动 |
