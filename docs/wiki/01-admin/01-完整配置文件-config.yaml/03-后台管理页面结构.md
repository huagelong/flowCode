### 后台管理页面结构

**系统管理**（URL: `/admin/`，super_admin 权限）：

```
/admin/                                  # 管理后台首页（仪表盘）
├── #dashboard                            系统概览（组织数/Agent数/今日Token用量/活跃任务）
├── /settings                             系统设置
│   ├── #agent          anserAgent 调度引擎（LLM / 讨论控制 / backlog 参数 / 记忆 / Skill 自改进 / 限流）
│   ├── #auth           认证（JWT 过期 / OAuth2 GitHub / CORS）
│   ├── #smtp           邮件（SMTP 服务器 / 发件人）
│   ├── #invite         邀请默认值（过期时间 / 使用次数）
│   ├── #sandbox        沙箱默认资源（CPU / 内存 / 磁盘 / 超时 / 网络白名单）
│   ├── #quota          Token 配额（组织级/项目级/Agent 级限制 + 告警阈值）
│   ├── #queue          任务队列（Asynq 并发 / 重试次数 / 超时）
│   └── #upgrade        自动更新（通道 / 检查间隔）
├── /organizations                        组织列表（CRUD + 进入下级管理）
├── /runtimes                             运行时管理（anserAgent / 扩展运行时 注册与配置）
├── /audit-logs                           操作审计日志（按组织/用户/操作/时间筛选）
└── /maintenance                          运维工具
    ├── worktree-cleanup     孤立的 git worktree 列表 + 手动清理
    ├── container-status     所有项目容器状态一览 + 强制重建
    └── queue-monitor        Asynq 队列积压监控
```

**组织管理**（URL: `/admin/organizations/{id}/`，owner/admin 权限）：

```
/admin/organizations/{id}/
├── #overview                             组织概览（成员数/项目数/Token用量）
├── /settings                             组织设置
│   ├── 沙箱并发上限（默认继承全局，可覆盖）
│   ├── Token 月配额（默认继承全局，可覆盖）
│   ├── 邀请链接有效期
│   └── 其他组织级覆盖项
├── /members                              成员管理（添加/移除/修改角色/邀请记录）
├── /projects                             项目列表（CRUD + 进入项目设置）
├── /agents                               Agent 列表（CRUD + 配置编辑）
└── /audit-logs                           组织级操作审计日志
```

**Agent 配置**（URL: `/admin/agents/{id}/edit`）：

```
/admin/agents/{id}/edit                    # Agent 运行时配置
├── 运行时选择（下拉，根据 runtimes 表动态渲染）
│   ├── 选择后根据 config_schema 动态渲染配置表单
│   ├── API Key 加密字段（前端显示 ****，后端 AES 加解密）
│   └── 不同运行时字段不同（anseragent: provider/model/thinking）
├── Skills 绑定管理（继承运行时默认 + Agent 级覆盖）
├── System Prompt 编辑（Markdown 编辑器 + 实时预览）
└── 用量统计（当日/本周/本月 Token 用量图表）
```
