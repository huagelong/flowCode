### 模式 B：分布式部署

适合大规模（50+ 并发 Issue），Worker 可水平扩展：

```bash
# 节点 1: API 网关（可多实例 + 负载均衡）
anserflow gateway --config config.yaml

# 节点 2~N: Worker（仅处理沙箱任务）
anserflow worker --config config.yaml --mode sandbox

# 数据库/Redis: 独立部署或托管服务
```
