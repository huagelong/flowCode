### 3.3 ZIP 导入完整流程

```
POST /api/orgs/:org_id/skills/import/zip    Content-Type: multipart/form-data
  → 内存解压 ZIP（≤10MB, MaxBytesReader）
  → 校验必须有 SKILL.md
  → 解析 frontmatter → 写入 skills 表（source_type="zip", zip_hash=SHA256）
```

> ZIP 全程内存处理，≤10MB。SHA256 去重可选（当前不自动去重）。
